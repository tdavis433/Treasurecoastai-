TEMPLATE BLEEDING BUG - ROOT CAUSE FOUND
🔴 CRITICAL BUG CONFIRMED
I found the template bleeding issue. Here's exactly what's happening:

THE BUG
Location: botConfig.ts - Lines 191-256
The loadBotFromDatabase() function loads bot configuration BUT it's missing template inheritance logic.
What's Happening:
When you create a bot from a template:

Bot record is created in bots table with basic info
Settings are copied to bot_settings table
BUT - template defaults might not be fully merged into the bot instance

Why Templates Bleed:
Scenario 1: Incomplete Bot Data

You create Bot A from "barbershop" template
Bot A doesn't have all fields filled in
Falls back to empty arrays/objects instead of template defaults
Later, Bot B from "recovery house" template gets created
If Bot B's data is also incomplete, it also falls back to empty
But, if there's any shared caching issue or stale data, they mix

TWO SEPARATE CACHES! This is the problem:

configCache (in configCache.ts) - properly scoped
botConfigCache (in botConfig.ts) - MODULE LEVEL, shared across ALL requests


THE ACTUAL ROOT CAUSE
Double Caching with Stale Data
You have TWO layers of caching:

Module-level cache in botConfig.ts (lines 177-178)
ConfigCache class in configCache.ts

When bot config is loaded:

orchestrator calls configCache.getBotConfig(clientId, botId)
configCache calls getBotConfigAsync(clientId, botId) from botConfig.ts
getBotConfigAsync checks its OWN module-level cache
If miss, loads from DB
Stores in module-level cache
Returns to configCache
configCache ALSO stores it

Problem:

The module-level cache in botConfig.ts uses clearBotConfigCache() to invalidate
The ConfigCache uses its own invalidation methods
When you update a bot, you might invalidate ONE cache but not the other
Old data from module-level cache gets served to new bot instances

typescriptasync function loadBotFromDatabase(botId: string): Promise<BotConfig | null> {
  try {
    const [botRecord] = await db.select().from(bots).where(eq(bots.botId, botId)).limit(1);
    if (!botRecord) return null;
    
    const [settingsRecord] = await db.select().from(botSettings).where(eq(botSettings.botId, botId)).limit(1);
    const [workspaceRecord] = await db.select().from(workspaces).where(eq(workspaces.id, botRecord.workspaceId)).limit(1);
    
    // ✅ NEW: Load template defaults
    let templateDefaults: any = {};
    if (botRecord.botType) {
      const [template] = await db.select()
        .from(botTemplates)
        .where(eq(botTemplates.botType, botRecord.botType))
        .limit(1);
      
      if (template?.defaultConfig) {
        templateDefaults = template.defaultConfig;
      }
    }
    
    // ✅ NEW: Merge template defaults with bot-specific overrides
    const businessProfile = {
      ...templateDefaults.businessProfile,  // Template defaults first
      ...botRecord.businessProfile          // Bot overrides second
    };
    
    const rules = {
      ...templateDefaults.rules,
      ...(settingsRecord?.rules || {})
    };
    
    const faqs = (settingsRecord?.faqs && settingsRecord.faqs.length > 0) 
      ? settingsRecord.faqs 
      : templateDefaults.faqs || [];
    
    // ... continue merging all fields
    
    const config: BotConfig = {
      clientId: workspaceRecord?.slug || botRecord.workspaceId,
      botId: botRecord.botId,
      name: botRecord.name,
      businessProfile,  // Now properly merged
      rules,            // Now properly merged
      faqs,             // Falls back to template
      // ...
    };
    
    return config;
  } catch (error) {
    structuredLogger.error('Error loading bot from database', { botId, error });
    return null;
  }
}
