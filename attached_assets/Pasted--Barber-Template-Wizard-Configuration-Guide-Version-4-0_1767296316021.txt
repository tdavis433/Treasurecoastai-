## 🔧 TECHNICAL IMPLEMENTATION

### **Variable Replacement System**

The wizard should perform these replacements:

```javascript
const templateReplacements = {
  // Basic Info
  '{{SHOP_NAME}}': formData.shopName,
  '{{PHONE}}': formData.phone,
  '{{EMAIL}}': formData.email || 'contact@shop.com',
  '{{WEBSITE}}': formData.website || '',
  
  // Address
  '{{FULL_ADDRESS}}': `${formData.street}, ${formData.city}, ${formData.state} ${formData.zip}`,
  '{{STREET_ADDRESS}}': formData.street,
  '{{CITY}}': formData.city,
  '{{STATE}}': formData.state,
  '{{ZIP}}': formData.zip,
  '{{ENCODED_ADDRESS}}': encodeURIComponent(`${formData.street}, ${formData.city}, ${formData.state} ${formData.zip}`),
  '{{APPLE_MAPS_LINK}}': generateAppleMapsLink(formData.address),
  '{{GOOGLE_MAPS_LINK}}': generateGoogleMapsLink(formData.address),
  
  // Hours
  '{{HOURS_SUMMARY}}': generateHoursSummary(formData.hours),
  '{{MONDAY_HOURS}}': formData.hours.monday || 'Closed',
  '{{TUESDAY_HOURS}}': formData.hours.tuesday.display || 'Closed',
  // ... etc for each day
  '{{TIMEZONE}}': formData.timezone || 'America/New_York',
  
  // Services
  '{{PRICING_SUMMARY}}': generatePricingSummary(formData.services),
  '{{PRICING_MENU_TEXT}}': generatePricingMenu(formData.services),
  '{{BEARD_PRICE}}': findServicePrice(formData.services, 'beard_trim'),
  '{{BEARD_COMBO_PRICE}}': findServiceComboPrice(formData.services, 'beard_trim'),
  '{{KIDS_PRICE}}': findServicePrice(formData.services, 'kids_cut'),
  '{{HOT_SHAVE_PRICE}}': findServicePrice(formData.services, 'hot_shave'),
  '{{DESIGN_PRICE}}': findServicePrice(formData.services, 'hair_design'),
  
  // Barbers
  '{{BARBER_LIST}}': generateBarberList(formData.barbers),
  '{{BARBER_INFO_TEXT}}': generateBarberInfo(formData.barbers),
  '{{BARBER_1_NAME}}': formData.barbers[0]?.name || '',
  '{{BARBER_1_SPECIALTY}}': formData.barbers[0]?.specialty || '',
  '{{BARBER_1_EXPERIENCE}}': formData.barbers[0]?.experience || '',
  '{{BEARD_SPECIALIST}}': findBarberBySpecialty(formData.barbers, 'beard') || formData.barbers[0]?.name,
  '{{SHAVE_SPECIALIST}}': findBarberBySpecialty(formData.barbers, 'shave') || formData.barbers[0]?.name,
  '{{DESIGN_SPECIALIST}}': findBarberBySpecialty(formData.barbers, 'design') || formData.barbers[0]?.name,
  
  // Booking
  '{{BOOKING_URL}}': formData.bookingUrl,
  '{{BOOKING_PROVIDER}}': formData.bookingProvider || 'custom',
  
  // Policies
  '{{CANCELLATION_POLICY}}': formData.cancellationPolicy || DEFAULT_CANCELLATION_POLICY,
  '{{LATE_POLICY}}': formData.latePolicy || DEFAULT_LATE_POLICY
};
```

### **Helper Functions**

```javascript
function generateHoursSummary(hours) {
  // Example: "Tue-Fri 10am-7pm (Thu-Fri until 8pm), Sat 9am-5pm. Closed Sun-Mon."
  // Logic to condense hours into readable format
}

function generatePricingSummary(services) {
  // Example: "Classic cuts $30, fades $35, skin fades $40. Kids $22, seniors $25."
  const activeServices = services.filter(s => s.active !== false);
  return activeServices.slice(0, 5).map(s => `${s.name} $${s.price}`).join(', ');
}

function generatePricingMenu(services) {
  // Full formatted menu for system prompt
  return services.map(s => `- ${s.name}: $${s.price}${s.priceNote ? ` (${s.priceNote})` : ''}`).join('\n');
}

function generateBarberList(barbers) {
  // Example: "Marcus (fades & designs), Tony (classic cuts & shaves), Devon (beards & textured cuts)"
  return barbers.map(b => `${b.name} (${b.specialty})`).join(', ');
}

function generateBarberInfo(barbers) {
  // For system prompt
  return barbers.map(b => `- ${b.name}: ${b.specialty}, ${b.experience} experience`).join('\n');
}

function findServicePrice(services, serviceId) {
  const service = services.find(s => s.id === serviceId);
  return service ? `$${service.price}` : '$XX';
}

function findBarberBySpecialty(barbers, keyword) {
  const barber = barbers.find(b => b.specialty.toLowerCase().includes(keyword));
  return barber?.name || barbers[0]?.name;
}
```

## ✅ PRE-LAUNCH VALIDATION

Before allowing “Launch”, wizard must validate:

### **Required Fields:**

- ✅ Shop name is not empty
- ✅ Phone number is valid format
- ✅ Address is complete (street, city, state, zip)
- ✅ At least one barber added
- ✅ Booking URL is valid HTTPS URL
- ✅ At least 3 services with prices
- ✅ Hours configured for at least 3 days

### **Data Quality Checks:**

- ⚠️ Phone number is formatted consistently
- ⚠️ Booking URL actually works (test request)
- ⚠️ All prices are positive numbers
- ⚠️ Hours don’t overlap (close > open)
- ⚠️ Timezone is valid

### **Test Scenarios:**

Run these automatically and show results:

1. “What are your hours?” → Should return correct hours
1. “How much is a fade?” → Should return correct price
1. “Book an appointment” → Should trigger lead capture
1. Links are clickable → Booking URL, map links
