# Treasure Coast AI — Landing Page Pack (Static)

This folder is a ready-to-run static landing page that matches the mockup style you approved:
- Single, non-repeating background layer (cover)
- Bottom fade so the skyline/edge disappears into solid dark
- Neon-glass UI, cinematic glow, crisp type
- Hero + widget preview + built-for chips + steps + demo cards + pricing + final CTA + demo form

## Run locally
Just open `index.html` in a browser.

## Deploy (Replit / any static host)
Upload the whole folder (keep the structure) and serve it as a static site.

Files:
- index.html
- styles.css
- script.js
- assets/tca_bg.jpg
- assets/tca_logo_nav.png
- assets/tca_widget_mock.png

## Hook up real actions
- Replace #demo and #demos links with your real routes or booking link.
- Wire the form submission to your backend endpoint (or a simple webhook) when ready.
